> 记录时间：2026-10-10 18:38（Asia/Shanghai）

## 1. v2 做了什么（一句话）

用 Shizuku（shell, uid 2000）把**一个** App 挂到后台：它以 2×2 像素的"隐形小点"留在屏幕上，
因此仍被系统视为「可见」→ 不被冻结、继续运行；需要时点屏幕边上的图标条把浮窗弹出来看/操作，再点收回。

## 2. 定稿时的工作配置（关键，不要随意改）

| 项 | 值 | 说明 |
|---|---|---|
| 挂机对象 | `com.tencent.nrc` **userId = 999**（小米手机分身 XSpace） | **必须用分身那份**。主系统那份（userId 0）会自己顶成全屏、resize 不听话，实测表现为"变形 / 收起弹出不灵 / 转屏不自动收回" |
| 布局预设 | `SOLO_KEEPALIVE` | 槽位 0 = 整块可用区（当前可见的那个），其余 = 右下角 2×2 小点 |
| 场景 | 单槽位、`keepAlive = true` | 保活自动开，无开关 |
| 档位 | `FREEFORM_TILING` | 自由窗口 + 隐形保活 |
| 启动方式 | 打开 App **不自动启动**；点「启动」才启动 | |

## 3. 这一版包含的关键修复（都是真机验证过的）

1. **Shizuku 命令通道**：`ShizukuRemoteProcess` 继承的 `waitFor(timeout)` 只认 `IllegalThreadStateException`，
   而服务端异常经 Binder 变成 `IllegalArgumentException` → 命令一启动就失败。改为自己轮询 `exitValue()`。
2. **浮窗刚弹出时渲染坏的**（游戏按钮丢失、触控失效）：靠**两次摆位**（先摆到目标尺寸的 3/5、350ms 后再摆到目标）触发一次配置变化，等效于"手动切一次横竖屏"。**这是 v2 能用起来的分水岭。**
3. **横屏浮窗又窄又小**：`ScreenMetrics` 取的是自然方向尺寸（永远竖的 1220×2656），横屏时必须把长边当宽用。
4. **收起状态下转屏会自己弹出**：`WorkbenchService.onConfigurationChanged` + 2 秒看门狗，双保险立刻校正。
5. **看门狗把用户的选择掰回去**：校正必须按"当前窗口顺序"而不是场景原始顺序。
6. **打开工作台却自动开工**：`am force-stop` 会把 App 置为 stopped，系统随后**补发排队的 `BOOT_COMPLETED`**，
   开机自启接收器就顺手把场景拉起来了。已停用该分支（**这条坑很隐蔽**）。
7. **点「启动」后主界面不消失**：首页页签漏了 `moveTaskToBack`。
8. **分身应用二次启动弹"选哪一个 nrc"**：不要在没有用户号的情况下 `am start`；所有启动命令统一由
   `FreeformController.amStart()` 注入 `--user N`。

## 5. 已知限制（v3 可考虑的方向）

- 转屏瞬间浮窗会**闪一下**（系统把 2×2 当"最小化"，转屏时它会还原成上一次大小，我们随后压回去）。
  ROM 层面无法完全消除；把看门狗间隔从 2 秒缩到 0.5 秒能减轻，但会增加命令调用频率。
- `com.tencent.nrc`（主系统那份）**拒绝进入自由窗口**，只能整屏；分身那份正常。
- 浮窗与游戏画面的比例：目前按 16:9 给窗口（画面铺满）。比例只由 `overlayBounds()` 里几个数字决定，随时可调。
- App 图标是**手绘的 DeepSeek 风格蓝色小鲸鱼**（占画布约 1/3），不是官方原图。

## 6. 开发/调试备忘

- 编译（必须放宽沙箱，否则 Gradle 原生库加载失败）：
  ```
  $env:JAVA_HOME = 'D:\AndroidDev\jdk-17'
  & 'D:\AndroidDev\gradle-8.9\bin\gradle.bat' --no-daemon --console=plain assembleDebug
  ```
- 安装：`adb install -r app\build\outputs\apk\debug\app-debug.apk`（手机已开「USB 安装」）
- **诊断通道**：这台 HyperOS 4 的 logcat main 缓冲被系统抽干（读不到任何日志），
  所以关键路径都写进 `/sdcard/Android/data/com.onestep.workbench/files/diag.log`，
  用 `adb shell cat/grep` 直接读。**排查任何问题都先看这个文件。**
- 崩溃只能靠 `adb shell dumpsys dropbox --print` 读。
- 快照目录 `onestep-workbench-snapshots\` 里每个版本都带 `src` + `app-debug.apk`，可随时回退。
