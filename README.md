# DSH-development-project-1

Android 应用开发仓库（配合 DeepSeek Harness 使用）。

## 目录约定

- `app/`            Android 应用模块（由 Android Studio 生成）
- `docs/`           设计与开发笔记
- `.gitignore`      已预置 Android / Gradle / IDE / Node 忽略规则

## 日常使用

打开根目录下的 `Open-Git-Shell.cmd` 会得到一个已配置好 Git 的命令行窗口，
在其中执行常用的 Git 命令即可：

```bat
git status
git add .
git commit -m "描述这次改动"
git push
```
